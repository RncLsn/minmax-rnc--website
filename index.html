1The goalEnsuring the four properties for truly long-sequence processing

Any model for truly long-sequence processing needs the following four properties:

Expressivity Efficiency Stability Sensitivity

Description of the four properties

High Expressivity

Long-term memory & State tracking

Recognise rich temporal patterns: from simple ones, like “B happened after A”, up to everything a finite-memory system can recognise. The two fundamental abilities are:

  • Long-term memory: storing information reliably as long as needed;
  • State tracking: manipulating such information in rich ways.
  • Sequence matching: follow patterns of several events that must occur in a given order, starting over whenever a reset event appears; the evidence is scattered across the whole sequence.
  • Recall: when asked, return a token that has occurred in a specific context, however far back.
  • State tracking: follow a sequence of rearrangements of n objects (the word problem of the group Sn); the current arrangement depends on every step and on their order.

The patterns a finite-memory system can recognise are the regular languages, the ones recognised by finite automata. By the Krohn–Rhodes theorem, every automaton can be realised by a cascade of two kinds of building blocks: identity-reset machines, which store a value and keep it unchanged until it is overwritten (long-term memory), and permutation machines, which rearrange information reversibly (state tracking).

The patterns that need only the first kind are the star-free languages. Sequence matching and recall are of this kind, while state tracking also needs permutations.

Computational Efficiency

Subquadratic in parallel & Constant per token

Process whole sequences efficiently in parallel, and be efficient also when processing them in multiple sequential steps. The cost should be:

  • Subquadratic in parallel: processing a whole sequence at once (say during training) costs less than quadratic time in its length, with only a short chain of steps that must wait for one another, so the work spreads across many processors;
  • Constant per token: processing one token at a time (say when reading a stream or generating text), each additional token costs a fixed amount of time and memory, however long the history.
  • Long contexts: today’s attention-based models compare every token with every other, so cost grows with the square of the length: a context ten times longer needs a hundred times the compute. This is why long contexts are slow, expensive and capped.
  • Streaming and generation: an assistant or agent reading a live stream or writing a long output should not slow down, or need more memory, as the history grows; with attention, every new token looks back at the whole history, held in a cache that keeps growing.
  • Training on long sequences: to train in reasonable time, GPUs need work they can spread across the whole sequence, which a strictly step-by-step recurrence cannot offer.

Cost that grows only linearly with length, constant per token, is what would make truly long contexts affordable.

Two measures matter in parallel. Work is the total number of operations. Depth is the longest chain of steps that must wait for one another, which sets the running time when there are enough processors. For a sequence of length T, we want work that grows less than quadratically (ideally linearly) in T and depth far below T, for example logarithmic. In recurrent form, each new token should cost a fixed amount of time and memory, however many tokens came before it.

Guaranteed Stability

Independent of sequence length

Stay bounded at any length: as long as every input value and every parameter stays within a fixed range, activations and gradients admit a bound that does not depend on the length of input sequences.

  • Amplification: if each update can enlarge the state even a little, the state can grow without limit over a long sequence.
  • Accumulation: even without amplification, inputs that are added at every step can pile up. States then drift away, and gradients grow with sequence length.

This matters in practice: a model trained on thousands of tokens and used on millions would meet activation sizes it has never seen if those sizes depended on length.

Bounded input, bounded activations: for any bound on the size of inputs and parameters, there is a single constant that bounds every internal activation and every output, at every position, for sequences of any length. The same requirement applies to training: the gradient of the loss with respect to the parameters must stay below a constant that does not depend on sequence length.

Long-Range Sensitivity

Error signal can reach distant steps

Learn long-range dependencies: when a late output is wrong, the error signal must flow back to the early inputs that caused it, without fading over the steps in between.

  • A switch set early: to learn that a flag at the first token decides an output a million tokens later, the error at that output must reach back to the first token.
  • Tracking a state: to learn to follow parity, or a shuffle of items, the error at the end must reach every earlier input, since each one can change the answer.

Without it, learning stalls: when the error signal shrinks with distance, as in contractive models, a late output hardly informs the training of early inputs, so such dependencies are not learned, even by a model that could represent them.

To learn a dependency between an early input and a late output, the derivative of that output, or of the training loss, with respect to the early input (or to the model’s internal representation of it) must stay away from zero, however far apart the two are. If it shrinks with distance, errors at late outputs send almost no learning signal back. In recurrent models this derivative is a product of one factor per step, which vanishes if every factor shrinks; in attention-based models it flows through attention weights, which can thin out as the context grows. Non-vanishing means that there are inputs for which this derivative keeps its size at any distance; together with bounded gradients (see Stability), it neither explodes nor fades.

2The gapToday’s architectures trade the four properties off

Nonlinear RNNs such as LSTMs and GRUs led sequence modelling through the 2010s. Since 2017, Transformers have taken over, and in the last few years Linear RNNs, such as Mamba, mLSTM and DeltaNet, have emerged as efficient alternatives.

Nonlinear RNNs. Elman networks (1990), LSTMs (1997) and GRUs (2014) update their state through squashing nonlinearities such as tanh and sigmoid. They are expressive, since nonlinear updates can implement finite-state machines, and stable, since activations stay bounded. But each update depends nonlinearly on the previous one, which prevents parallelisation, and the error signal vanishes over long distances.

Transformers. Introduced in 2017, they replace recurrence with attention, which compares every token with every earlier one. Activations and gradients stay bounded, but work grows quadratically with sequence length; they cannot express simple common patterns that a finite-state machine recognises easily; and the influence of a single early input is diluted as the context grows.

Linear RNNs. They return to recurrence with a linear state update, which can be run one step at a time or, since updates compose associatively, over a whole sequence with a parallel scan. They come in two kinds. Contractive ones, such as Mamba, mLSTM and Gated DeltaNet, shrink the state at every step: states and gradients stay bounded, but old information fades, which limits expressivity and long-range sensitivity. Non-expansive ones, such as DeltaNet and DeltaProduct, use transitions that preserve the state’s size, such as reflections, gaining expressivity and long-range sensitivity, but their gradients can diverge.

3The ideaReinterpret Linear Recurrence:  Standard +,× → MinMax ⊕,⊗

At the heart of MinMax RNCs is MinMax recurrence: it is linear recurrence but with sum and product being those of the MinMax algebra.

Using max in place of + and min in place of × on scalars, we obtain operations ⊕,⊗ on vectors and matrices that have the familiar algebraic properties (associativity, commutativity, distributivity), while also being selective: they do not create new values, since they return one of their arguments, unlike +,×.

On scalars. a⊕b=max(a,b) and a⊗b=min(a,b).

On matrices and vectors. With max in place of sums and min in place of products, ⊕ works entry by entry,

(A⊕B)ij=Aij⊕Bij=max(Aij,Bij) (A⊕B)ij=Aij⊕Bij=max(Aij,Bij)

and ⊗ is the usual matrix product:

(A⊗B)ij=⨁k(Aik⊗Bkj)=maxkmin(Aik,Bkj) (A⊗B)ij=⨁k(Aik⊗Bkj)=maxkmin(Aik,Bkj)

Associativity, commutativity, distributivity. Like +,×, both ⊕ and ⊗ are associative and commutative, and ⊗ distributes over ⊕, just as × distributes over +. These properties are what let a whole sequence be processed with a parallel scan (see Why it works).

Selectivity. Unlike +,×, the operations ⊕,⊗ never create new values: they only pick one of their arguments. This is what keeps MinMax RNCs stable however long the sequence (see Why it works).

MinMax RNCs are cascades of layers of MinMax recurrent neurons, each maintaining its state through MinMax recurrence, using feedforward networks R and s to compute, from the current input ut, the values Rt=R(ut) and st=s(ut) that drive its update.

4Why it worksMinMax RNCs have all four properties

Swapping +,× for ⊕,⊗ is a simple change, but it is enough to guarantee all four properties.

Expressivity Efficiency Stability Sensitivity

The properties of MinMax RNCs

High Expressivity

Long-term memory & State tracking

Exactly the regular languages: MinMax RNCs capture all regular languages and nothing beyond. Both fundamental abilities come from MinMax recurrence itself:

  • Long-term memory: a neuron holding a single number can keep its value exactly, or overwrite it, depending on the input; such neurons already suffice to capture the star-free languages;
  • State tracking: a neuron with a vector state can reorder its entries at every step, which is what tracking a permutation of objects requires.

Over finite alphabets, MinMax RNCs can implement every regular function, and nothing beyond: whatever they compute could also be computed by a finite-state machine. Restricted to scalar-state neurons, they implement exactly the group-free functions, which recognise the star-free languages. Both claims also hold with a positive margin: outputs stay decodable with a fixed separation, however long the sequence.

Every finite-state machine decomposes into a cascade of two kinds of simple machines, and MinMax neurons realise both:

  • Identity–reset (store a value, keep it, or overwrite it): a scalar neuron suffices. When st≤Rt, the update xt=(Rt⊗xt−1)⊕st leaves any state between them unchanged; when st>Rt, it resets the state to st.
  • Permutations (rearrange stored values, as in counting modulo n): a neuron with an n-dimensional state, where n is the degree of the permutation group, copies each entry of the old state into a chosen entry of the new one, by setting one entry per row of Rt high and the rest low.

Scalar neurons cannot permute: with fixed inputs, their state settles in at most two steps. That is why they stop at the group-free functions.

Computational Efficiency

Linear in parallel & Constant per token

Nonlinear, yet parallelisable: unlike classic nonlinear RNNs, MinMax recurrence composes associatively, despite ⊕,⊗ being nonlinear. This meets both requirements:

  • Linear in parallel: a parallel scan processes a whole sequence with work linear in its length and only logarithmically many steps that must wait for one another;
  • Constant per token: the state has a fixed size, so each new token involves a single MinMax update, whatever the length of the history, with no cache that grows as in Transformers.

Each update costs one matrix–vector product, so a neuron with d-dimensional state processes T tokens in time O(T·d2): constant per token, as for any recurrent network.

Each update is a map x↦(Rt⊗x)⊕st, so it is described by the pair (Rt,st). Composing two such maps, first (Ri,si) and then (Rj,sj), gives a map of the same form, with pair

(Ri,si)(Rj,sj)=(Rj⊗Ri,(Rj⊗si)⊕sj)

The composition operator is associative, so the pairs (R1:t,s1:t)=(R1,s1)⋯(Rt,st), which give every state as xt=(R1:t⊗x0)⊕s1:t, can all be computed with a parallel scan: depth O(logT·logd), work O(T·d3).

The same holds layer by layer: a MinMax RNC of fixed size runs in time O(logT) on Θ(T) processors, and its total work stays linear in T.

Guaranteed Stability

Independent of sequence length

Stable at any length: since min,max only select among their inputs, so do ⊕,⊗, ensuring that states, outputs and gradients stay below a bound that does not depend on sequence length.

One update can never exceed its input-dependent values: ‖xt‖max≤max{‖Rt‖max,‖st‖max}, whatever the previous state. Since Rt and st come from MLPs, they are bounded on bounded inputs and parameters; so are all states and outputs, layer after layer, with a bound that does not depend on sequence length.

Max and min pass gradients on with non-negative weights that sum to one, so the recurrence never enlarges them over time. The gradient of the loss is therefore bounded too, independently of length. The gradient that automatic differentiation computes (as in PyTorch) agrees with the true gradient almost everywhere.

Long-Range Sensitivity

via non-vanishing gradients

State gradients need not vanish: a neuron can carry its state unchanged, or with its entries reordered, across any number of steps, so gradients between distant steps keep full strength and the model can learn dependencies spanning arbitrarily long ranges.

The neurons behind the expressivity results act on their states either as the identity or as a permutation of entries, with no ties among the arguments of max and min. Over any number of steps, the derivative of the state with respect to an earlier state is then a permutation matrix: its norm is exactly one, so it neither vanishes nor explodes.

The training signal from a late output can flow back to an input that occurred arbitrarily long before, at full strength. Combined with stability, this gives non-vanishing yet bounded gradients.
