1The goalEnsuring the four properties for truly long-sequence processing

Expressivity Efficiency Stability Sensitivity

Any model for truly long sequences needs all four, and ensuring them at once is hard.

Each of the properties is detailed below.

High Expressivity

Long-term memory & state tracking

Recognise rich temporal patterns: from simple ones, like “B happened after A”, up to everything a finite-memory system can recognise. The two fundamental abilities are:

  • Long-term memory: storing information reliably as long as needed;
  • State tracking: manipulating such information in rich ways.

More examples.

  • Sequence matching: follow patterns of several events that must occur in a given order, starting over whenever a reset event appears; the evidence is scattered across the whole sequence.
  • Recall: return the very first token of the sequence or, at the second occurrence of a marker, the token that came right after its first occurrence, however far back.
  • State tracking: follow a sequence of rearrangements of 3 or 4 objects (the word problems of the groups S3 and S4); the current arrangement depends on every step and on their order.

The automata view. The patterns a finite-memory system can recognise are the regular languages, the ones recognised by finite automata. By the Krohn–Rhodes theorem, every automaton can be simulated by a cascade of two kinds of building blocks: identity-reset blocks, which store a value and keep it unchanged until it is overwritten (long-term memory), and permutation blocks, which rearrange information reversibly (state tracking).

The patterns that need only the first kind are the star-free languages. Sequence matching and recall are of this kind, while S3 and S4 also need permutations.

Computational Efficiency

Subquadratic in parallel & Constant per token

Process whole sequences efficiently in parallel, and be efficient also when processing them in multiple sequential steps. The cost should be:

  • Subquadratic in parallel: processing a whole sequence at once (say during training) costs less than quadratic time in its length, with only a short chain of steps that must wait for one another, so the work spreads across many processors;
  • Constant per token: processing one token at a time (say when reading a stream or generating text), each additional token costs a fixed amount of time and memory, however long the history.

Examples.

  • Long documents: full self-attention compares every token with every other, so doubling the length roughly quadruples the cost.
  • Streaming and generation: a model reading a live stream or writing text token by token should not slow down, or need more memory, as the history grows.
  • Training on long sequences: GPUs need work they can spread across the whole sequence, which a strictly step-by-step recurrence cannot offer.

The precise notion. Two measures matter in parallel. Work is the total number of operations. Depth is the longest chain of steps that must wait for one another, which sets the running time when there are enough processors. For a sequence of length T, we want work that grows less than quadratically (ideally linearly) in T and depth far below T, for example logarithmic. In recurrent form, each new token should cost a fixed amount of time and memory, however many tokens came before it.

Guaranteed Stability

Independent of sequence length

Stay bounded at any length: as long as every input value and every parameter stays within a fixed range, activations and gradients admit a bound that does not depend on the length of input sequences.

Examples.

  • Amplification: if each update can enlarge the state even a little, the state can grow without limit over a long sequence.
  • Accumulation: even without amplification, inputs that are added at every step can pile up. States then drift away, and gradients grow with sequence length.
  • Train short, run long: a model trained on thousands of tokens and used on millions would meet activation sizes it has never seen if those sizes depended on length.

The precise notion. Bounded input, bounded state: for any bound on the size of inputs and parameters, there is a single constant that bounds every state and output at every timestep, for sequences of any length. The same requirement applies to training: the gradient of the loss with respect to the parameters must stay below a constant that does not depend on sequence length.

Long-Range Sensitivity

Error signal can reach distant steps

Learn long-range dependencies: when a late output is wrong, the error signal must flow back to the early inputs that caused it, without fading over the steps in between.

Examples.

  • A switch set early: a flag turned on at the first token must still decide the output a million tokens later.
  • Tracking a state: following parity, or a shuffle of items, means every input up to the end can change the answer.
  • Fading memory: in contractive models, a long enough stretch of recent input wipes out the influence of earlier input.

The precise notion. To learn a dependency between an early input and a late output, the derivative of that output, or of the training loss, with respect to the early input (or to the model’s internal representation of it) must stay away from zero, however far apart the two are. If it shrinks with distance, errors at late outputs send almost no learning signal back. In recurrent models this derivative is a product of one factor per step, which vanishes if every factor shrinks; in attention-based models it flows through attention weights, which can thin out as the context grows. Non-vanishing means that there are inputs for which this derivative keeps its size at any distance; together with bounded gradients (see Stability), it neither explodes nor fades.

2The gapToday’s architectures trade the four properties off

Nonlinear RNNs such as LSTMs and GRUs led sequence modelling through the 2010s. Since 2017, Transformers have taken over, and in the last few years Linear RNNs, such as Mamba and DeltaNet, have emerged as efficient alternatives.

Nonlinear RNNs. Elman networks (1990), LSTMs (1997) and GRUs (2014) update their state through squashing nonlinearities such as tanh and sigmoid. They are expressive, since nonlinear updates can implement finite-state machines, and stable, since activations stay bounded. But each update depends nonlinearly on the previous one, which prevents parallelisation, and the error signal vanishes over long distances.

Transformers. Introduced in 2017, they replace recurrence with attention, which compares every token with every earlier one. Activations and gradients stay bounded, but work grows quadratically with sequence length; they cannot express simple common patterns that a finite-state machine recognises easily; and the influence of a single early input is diluted as the context grows.

Linear RNNs. They return to recurrence with a linear state update, which can be run one step at a time or, since updates compose associatively, over a whole sequence with a parallel scan. They come in two kinds. Contractive ones, such as Mamba, mLSTM and Gated DeltaNet, shrink the state at every step: states and gradients stay bounded, but old information fades, which limits expressivity and long-range sensitivity. Non-expansive ones, such as DeltaNet and DeltaProduct, use transitions that preserve the state’s size, such as reflections, gaining expressivity and long-range sensitivity, but their gradients can diverge.

3The ideaReinterpret linear recurrence: Standard +,× → MinMax ⊕,⊗

The MinMax algebra. The standard arithmetic operations +,× have MinMax counterparts ⊕,⊗. On scalars, they replace sum and product with maximum and minimum, a⊕b=max(a,b) and a⊗b=min(a,b); on vectors and matrices, they then work just like +,×, with ⊕ in place of + and ⊗ in place of ×.

The operations ⊕,⊗ retain the key properties of +,× while having an extra one:

  • Associativity, Commutativity, Distributivity: they hold just as for +,×;
  • Selectivity: they do not create new values, since they return one of their arguments, unlike +,×.

On matrices and vectors. With max in place of sums and min in place of products, ⊕ works entry by entry,

(A⊕B)ij=Aij⊕Bij=max(Aij,Bij) (A⊕B)ij=Aij⊕Bij=max(Aij,Bij)

and ⊗ is the usual matrix product:

(A⊗B)ij=⨁k(Aik⊗Bkj)=maxkmin(Aik,Bkj) (A⊗B)ij=⨁k(Aik⊗Bkj)=maxkmin(Aik,Bkj)

Associativity, commutativity, distributivity. Like +,×, both ⊕ and ⊗ are associative and commutative, and ⊗ distributes over ⊕, just as × distributes over +. These properties are what let a whole sequence be processed with a parallel scan (see Why it works).

Selectivity. Unlike +,×, the operations ⊕,⊗ never create new values: they only pick one of their arguments. This is what keeps MinMax RNCs stable however long the sequence (see Why it works).

MinMax RNCs are cascades of layers of MinMax recurrent neurons, each maintaining its state through MinMax recurrence, using feedforward networks to compute the input-dependent values that drive its update.

Scalar MinMax Recurrent Neurons

To start simple, we first look at neurons whose state is a single number. Each neuron keeps a scalar state xt that updates at every step by computing a reset value R(ut) and a set value s(ut) from the current input ut, and then applying MinMax recurrence:

Choose notation
xt=max(min(R(ut),xt−1),s(ut))
xt=(R(ut)⊗xt−1)⊕s(ut)

In words: keep the old state, but reset it down to R(ut) if it is higher, and then set the result to s(ut) if it is lower.

General MinMax Recurrent Neurons

In the general case, the state is a vector. Each neuron keeps a d-dimensional state xt that updates at every step by computing a d-by-d reset matrix R(ut) and a d-dimensional set vector s(ut) from the current input ut, and then applying MinMax recurrence:

Choose notation
xt,i=max(max1≤j≤dmin(R(ut)ij,xt−1,j),s(ut)i)
xt=(R(ut)⊗xt−1)⊕s(ut)

In words: entry i of the new state is the largest of the old entries, each first reset down to at most its entry of R(ut), and then set up to at least its entry of s(ut).

4Why it worksAll four properties guaranteed: expressive, efficient, stable, long-range

Max and min are simple, but they give MinMax RNCs all four properties, provably.

High Expressivity

Long-term memory & state tracking

MinMax neurons can implement all the basic building blocks of finite-state machines, so MinMax RNCs capture all regular languages. Scalar-state neurons already suffice to capture the star-free languages.

Computational Efficiency

Subquadratic in parallel & Constant per token

Updates can be run one step at a time, like any recurrent network. They also compose associatively, so a whole sequence can be processed with a parallel scan.

Guaranteed Stability

Independent of sequence length

Max and min only ever select one of their inputs; they never amplify. States and activations stay bounded at every length, and so do the gradients used in training.

Long-Range Sensitivity

via non-vanishing gradients

A neuron can carry its state unchanged, or permuted, across any number of steps. Gradients between distant states can then keep full strength, instead of vanishing.
