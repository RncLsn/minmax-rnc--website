1What long sequences demand

To process truly long sequences, a model needs four properties at once, and getting all four together is hard.

Four key properties

High Expressivity

with long-term memory

Remember what matters for as long as needed, and recognise rich temporal patterns: from simple ones, like “B happened after A”, up to everything a finite-memory system can recognise.

Computational Efficiency

Subquadratic in parallel & Constant per token

Subquadratic cost for processing an entire sequence in parallel, and constant cost for each additional token.

Guaranteed Stability

Independent of sequence length

Activations and gradients stay bounded, no matter how long the sequence gets.

Long-Range Sensitivity

Non-vanishing gradients

Early inputs can still shape late outputs, so dependencies across very long distances can be learned.

3The idea

Choose state dimension

Linear recurrence in the MinMax algebra

Reinterpret linear recurrence replacing ordinary arithmetic operations +,× with their MinMax counterparts ⊕,⊗, which are. On scalars, they are a⊕b=max(a,b) and a⊗b=min(a,b), and then they apply to vectors and matrices analogously to +,×.

Linear recurrence
xt=(at×xt−1)+btxt=(At×xt−1)+bt
→ MinMax recurrence
xt=(at⊗xt−1)⊕btxt=(At⊗xt−1)⊕bt

On matrices and vectors. With max in place of sums and min in place of products, ⊕ works entry by entry,

(A⊕B)ij=Aij⊕Bij=max(Aij,Bij) (A⊕B)ij=Aij⊕Bij=max(Aij,Bij)

and ⊗ is the usual matrix product:

(A⊗B)ij=⨁k(Aik⊗Bkj)=maxkmin(Aik,Bkj) (A⊗B)ij=⨁k(Aik⊗Bkj)=maxkmin(Aik,Bkj)

Associativity, commutativity, distributivity. Like +,×, both ⊕ and ⊗ are associative and commutative, and ⊗ distributes over ⊕, just as × distributes over +. These properties are what let a whole sequence be processed with a parallel scan (see Why it works).

Selectivity. Unlike +,×, the operations ⊕,⊗ never create new values: they only pick one of their arguments. This is what keeps MinMax RNCs stable however long the sequence (see Why it works).

MinMax Recurrent Neurons

Each neuron keeps a scalar state xt that updates at every step by computing a reset value R(ut) and a set value s(ut) from the current input ut, and then applying MinMax recurrence:

Choose notation
xt=max(min(R(ut),xt−1),s(ut))
xt=(R(ut)⊗xt−1)⊕s(ut)

In words: keep the old state, but reset it down to R(ut) if it is higher, and then set the result to s(ut) if it is lower.

Try it

Press Step to run the neuron one input at a time, starting from state 0. You can also edit the inputs.

StepReset RSet sUpdateState
1max(min(0, 0), 2) = 22
2max(min(7, 2), 0) = 22
3max(min(5, 2), 0) = 22
4max(min(0, 2), 1) = 11

The state is written once (step 1), held unchanged while R stays above it (steps 2 and 3), and overwritten at step 4, where a low R resets it and s sets it to 1. This kind of exact, lossless holding is what lets the model remember over arbitrarily long spans.

Each neuron keeps a d-dimensional state xt that updates at every step by computing a d-by-d reset matrix R(ut) and a d-dimensional set vector s(ut) from the current input ut, and then applying MinMax recurrence:

Choose notation
xt,i=max(max1≤j≤dmin(R(ut)ij,xt−1,j),s(ut)i)
xt=(R(ut)⊗xt−1)⊕s(ut)

In words: entry i of the new state is the largest of the old entries, each first reset down to at most its entry of R(ut), and then set up to at least its entry of s(ut).

Try it: a two-entry state that tracks parity

This neuron reads one number u per step, with reset R(u)=(1−uuu1−u) and set s=(00), starting from state x0=(10). So R(0) is the identity and R(1) swaps the two entries.

Press Step to run it one input at a time. You can also edit the inputs.

StepInput uUpdateState
1(0110)⊗(10)⊕(00)=(01)(01)
2(1001)⊗(01)⊕(00)=(01)(01)
3(0110)⊗(01)⊕(00)=(10)(10)
4(0110)⊗(10)⊕(00)=(01)(01)

6(1001)⊗(01)⊕(00)=(01)(01)

The neuron swaps its two state entries on input 1 and leaves them unchanged on input 0. Its state is (10) after an even number of 1s and (01) after an odd number: it implements parity. Swapping two entries needs a state of dimension two. In general, the state dimension of a neuron matches the degree of the permutations it can realise, and a single number already suffices for the star-free patterns.

Architecture of MinMax RNCs

A MinMax RNC is a cascade of layers of MinMax recurrent neurons, where each neuron’s R and s are computed from the input by a feedforward network.

4Why it works

Max and min are simple, but they give MinMax RNCs all four properties, provably.

High Expressivity

with long-term memory

MinMax neurons can implement all the basic building blocks of finite-state machines, so MinMax RNCs capture all regular languages. Scalar-state neurons already suffice to capture the star-free languages.

Computational Efficiency

Subquadratic in parallel & Constant per token

Updates can be run one step at a time, like any recurrent network. They also compose associatively, so a whole sequence can be processed with a parallel scan.

Guaranteed Stability

Independent of sequence length

Max and min only ever select one of their inputs; they never amplify. States and activations stay bounded at every length, and so do the gradients used in training.

Long-Range Sensitivity

via non-vanishing gradients

A neuron can carry its state unchanged, or permuted, across any number of steps. Gradients between distant states can then keep full strength, instead of vanishing.
